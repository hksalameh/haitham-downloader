# خارطة تطوير مدير تحميل هيثم مقارنةً بزاجِل

تاريخ الدراسة: 2026-10-31. المصادر: `motalim-ai/zajil-download-manager`، الإصدار `v1.2.2`، و`hksalameh/haitham-downloader`.

**الهدف:** الوصول إلى جودة وتجربة مماثلة أو أفضل دون التضحية بالواجهة الكلاسيكية أو الملفات الحالية. المقارنة على مستوى *الكود والاختبارات*؛ لا توجد مقارنة سرعة إنترنت مباشرة حتى الآن.

## المنجز في هذه المرحلة (قيد المراجعة)

- تقسيم ديناميكي **مستقل التنفيذ**: حين ينتهي عامل من جزئه، يأخذ نصف الذيل غير المستلم من اتصال نشط أبطأ؛ حد أعلى لعدد الأجزاء، مع حفظ خريطة الأجزاء قبل بدء اتصال جديد.
- تخزين الملفات الجزئية على قرص الوجهة افتراضيًا، وبناؤها بالترتيب الحقيقي للبايتات مع رفض أي فجوة أو تداخل.
- سقف 32 اتصالًا لمحرك HTTP Range، مع استمرار سقف 16 لمحرك aria2 الاحتياطي.
- اختبار محلي بملف 24 MiB وخادم يبطئ أول اتصال عمدًا، بالإضافة إلى مطابقة SHA-256، وإيقاف/استكمال بعد إعادة تشغيل المحرك، واختبارات 429 و503 وChrome.
- عند غياب `aria2` لا يفشل تشغيل التطبيق؛ يستطيع محرك HTTP Range تنزيل الروابط المباشرة المؤهلة، وتظهر رسالة واضحة للروابط التي تحتاج المحرك الاحتياطي. لم يُبنَ ملف EXE جديد بعد.

## الفجوات المتبقية — بالترتيب

1. **نزاهة الاستكمال على الخوادم المتغيرة:** تخزين ETag قوي أو Last-Modified موثوق، والتحقق قبل الاستكمال/خلاله، ورفض دمج إصدارات مختلفة من الملف؛ اختبارات تغيّر المحتوى مع بقاء الحجم نفسه.
2. **بدء البرنامج بواسطة المتصفح:** نقل تكامل Chrome تدريجيًا إلى Native Messaging موثق، ومنع نافذة الحفظ المزدوجة، والتأكد من استرداد التحميل في Chrome إن لم يقبله البرنامج، مع دعم Edge ثم Firefox.
3. **حفظ على القرص الخارجي:** اختبارات فصل/إعادة توصيل USB وانقطاع المساحة والحفظ مباشرة على القرص المختار؛ تقليل مساحة الدمج المؤقتة الإضافية.
4. **الثبات والأداء الواقعي:** اختبارات بمقاسات 1–5 GiB ومواقع مختلفة، ومقارنة Chrome/IDM/زاجِل على نفس الروابط والشبكة والتوقيت، وتوثيق حدود الخوادم التي تمنع التسريع.
5. **الفيديو والجدولة:** تحسين التقاط روابط الفيديو وصلاحيات الكوكيز بإذن المستخدم، وإعادة تحميل الروابط المنتهية، والصفوف وجدولة يوم/أسبوع بدقة.
6. **نسخة Windows موثوقة:** بناء تلقائي موقّع بالبصمات، فحص EXE على Windows 10/11، واختبار التحديث، والواجهة، وأيقونة الساعة دون نوافذ مزعجة.
7. **أنظمة أخرى:** Linux/macOS بعد فصل طبقة واجهة Windows والتحقق من المتطلبات، لا بمجرد نسخ ملف EXE.
