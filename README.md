# Haitham Downloader | مدير تحميل هيثم

برنامج مجاني ومفتوح المصدر لإدارة التحميلات، بواجهة عربية وتحميل متعدد الاتصالات واستكمال التحميلات وجدولتها.

**الحالة:** نسخة تطوير تجريبية بهوية مستقلة. تكامل Chrome الخاص بنا يحتاج إلى تنفيذ واختبار قبل الاستخدام اليومي.

**المستودع:** https://github.com/hksalameh/haitham-downloader

**ما سنضيفه:** إضافة كروم مرفقة بالمثبت، تذكّر آخر مجلد، التحميل مباشرة إلى القرص الخارجي، والعمل في شريط النظام.
